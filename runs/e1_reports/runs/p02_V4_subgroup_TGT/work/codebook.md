# Codebook

Unit: one row per firm (2000 software and engineering firms). Cross-section.

| column | description |
|---|---|
| firm_id | Firm identifier |
| remote_share | Share of engineering staff working mostly remote, 2021-2022 |
| patents_per_100_eng_2023 | Patent applications per 100 engineers in 2023 |
| log_engineers_2020 | Log number of engineers, 2020 |
| firm_age_2020 | Firm age in years, standardized, 2020 |
| patents_per_100_eng_2020 | Patent applications per 100 engineers in 2020, standardized |
| collab_index_2023 | Internal collaboration index from 2023 survey |
| region | Region (north, central, south) |
| listed | 1 if publicly listed |
| segment | Sector: hardware / software |
| vc_backed | Firm characteristic measured in 2020 (pre-period) |
| founder_ceo | Firm characteristic measured in 2020 (pre-period) |
| cloud_spend_2020 | Firm characteristic measured in 2020 (pre-period) |
| hq_in_hub_city | Firm characteristic measured in 2020 (pre-period) |
| share_phd_2020 | Firm characteristic measured in 2020 (pre-period) |
| gross_margin_2020 | Firm characteristic measured in 2020 (pre-period) |
