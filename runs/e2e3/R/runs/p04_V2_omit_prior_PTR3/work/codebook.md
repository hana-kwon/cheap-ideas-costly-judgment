# Codebook

Unit: one row per firm (2000 manufacturing and service firms). Cross-section.

| column | description |
|---|---|
| firm_id | Firm identifier |
| training_hours | Average annual training hours per employee, 2021-2022 |
| productivity_2023 | Value added per employee in 2023 (thousand USD) |
| log_employees_2020 | Log number of employees, 2020 |
| firm_age_2020 | Firm age in years, standardized, 2020 |
| productivity_2020 | Value added per employee in 2020, standardized |
| mgmt_rating_2023 | Management practices rating collected in 2023 survey |
| region | Region (north, central, south) |
| listed | 1 if publicly listed |
| sector | Sector: manufacturing / services |
| export_share_2020 | Firm characteristic measured in 2020 (pre-period) |
| foreign_owned | Firm characteristic measured in 2020 (pre-period) |
| family_owned | Firm characteristic measured in 2020 (pre-period) |
| rd_intensity_2020 | Firm characteristic measured in 2020 (pre-period) |
| union_share_2020 | Firm characteristic measured in 2020 (pre-period) |
| credit_score_2020 | Firm characteristic measured in 2020 (pre-period) |
