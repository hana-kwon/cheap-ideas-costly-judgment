# Codebook

Unit: one row per firm (2000 exporting manufacturers). Cross-section.

| column | description |
|---|---|
| firm_id | Firm identifier |
| supplier_diversity | Number of distinct input suppliers (standardized), 2021-2022 |
| export_growth_2023 | Export value growth in 2023 (percent index) |
| log_sales_2020 | Log sales, 2020 |
| years_exporting_2020 | Years since first export, standardized, 2020 |
| export_growth_2020 | Export value growth in 2020, standardized |
| buyer_rating_2023 | Average rating from foreign buyers, 2023 |
| region | Region (north, central, south) |
| listed | 1 if publicly listed |
| product_group | Sector: durables / nondurables |
| inventory_days_2020 | Firm characteristic measured in 2020 (pre-period) |
| foreign_owned | Firm characteristic measured in 2020 (pre-period) |
| share_imported_inputs_2020 | Firm characteristic measured in 2020 (pre-period) |
| port_distance_km | Firm characteristic measured in 2020 (pre-period) |
| certified_iso | Firm characteristic measured in 2020 (pre-period) |
| debt_ratio_2020 | Firm characteristic measured in 2020 (pre-period) |
