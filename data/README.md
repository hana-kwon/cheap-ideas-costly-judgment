# Data

All inputs are synthetic, generated by code in `src/` from fixed seeds, or model outputs on those synthetic inputs. No licensed, restricted or personal data are used, so there is nothing to download and everything can be redistributed. `inputs_manifest.json` lists every file with its size, SHA-256 and origin. Person, shop and supplier names in the ledger documents are invented labels; some supplier names resemble real businesses only as realistic decoration.

## Report task (`reports/`)

- `manifest.json`: the six datasets (effect 0.08 in two, 0.05 in two, zero in two), their cover stories and seeds, and the confounding strength (0.10).
- `datasets/p01` to `p06`: `data.csv` (2,000 synthetic firms) and `codebook.md`, the only files a model saw besides the report.
- `truth/`: for each dataset, the planted truth and the estimate in each of 256 plausible specifications (`*_specspace.csv`). Never placed in a model's working folder.
- `bank/`: 30 reports (5 per dataset: one correct, four with a planted flaw), each with `report.md`, `final_answer.json`, `analysis.py` and copies of the data and codebook, and `bank.csv`, the answer key (flaw, report conclusion, true conclusion, whether the conclusion is wrong).

Rebuild: `python src/01_make_report_datasets.py --out <dir>` then `python src/02_make_report_bank.py --datasets <dir>/datasets --truth <dir>/truth --out <dir>/bank`. Both outputs are byte-identical to the stored files (checked by `run_all.py`).

## Ledger task (`ledgers/`)

- `packets/`: 24 document sets (Kenya, Nigeria, India, United States x 40, 100, 160 transactions x versions a and b), each rendered as local informal text (`*_local.txt`) and as a standardized table (`*_standard.csv`), with the answer key (`*_answer_key.csv`), a scoring self-test and a recoverability check. Rebuild with `python src/03_make_ledger_packets.py --out <dir>` (byte-identical).
- `drafts/`: the 48 AI-drafted ledgers (`{packet}_{format}_r0.csv`) that are the starting point of every ledger experiment, written by claude-sonnet-5-5 from the documents (`src/04_draft_ledgers.py`), with the call records (`drafting_calls.jsonl`; each prompt's SHA-256 matches the prompt that `src/04` builds). These are model outputs and cannot be regenerated bit for bit; the drafting step can be rerun with any model.
- `seeded/`: the 48 drafts after seeding (one planted error in 8 percent of rows, flags fixed by design), as every structure received them. The experiments rebuild them in memory; `python src/05_seed_ledger_drafts.py --out <dir>` writes the same 48 files byte for byte.
